# StormStatistics-Java

StormStatistics-Java is a Java desktop application for working with storm data and displaying storm statistics through a graphical user interface (GUI).

The project demonstrates Java object-oriented programming, data processing, sorting and comparison techniques, and GUI development.

## Features

- Processes storm information
- Calculates and displays storm statistics
- Uses a graphical user interface
- Organizes storm information using Java objects
- Uses comparators to sort and compare storm data
- Demonstrates Java Swing GUI programming

## Technologies Used

- Java
- Java Swing
- Eclipse IDE
- Java Development Kit (JDK)

## Recommended Software

The project can be opened and run using **Eclipse IDE for Java Developers**.

Eclipse can be downloaded from the official Eclipse website.

You will also need a **Java Development Kit (JDK)** installed on your computer.

The project may also be opened with other Java development environments such as IntelliJ IDEA or Visual Studio Code with Java support installed.

## Project Structure

```text
StormStatistics-Java/
└── src/
    ├── Main.java
    ├── Storm.java
    └── Comparators.java
```

### Main.java

Contains the main application logic and launches the program's graphical user interface.

### Storm.java

Defines the storm objects and the information associated with individual storms.

### Comparators.java

Contains comparison logic used to organize and sort storm information.

## How to Run in Eclipse

1. Install the Java Development Kit (JDK).
2. Install Eclipse IDE for Java Developers.
3. Download or clone this repository.
4. Open Eclipse.
5. Import the project into your Eclipse workspace.
6. Make sure the `src` directory is configured as the project's source folder.
7. Open `Main.java`.
8. Select **Run → Run As → Java Application**.
9. The Storm Statistics graphical interface should open.

Because this application uses a graphical user interface, it should be run on a computer with a desktop environment.
